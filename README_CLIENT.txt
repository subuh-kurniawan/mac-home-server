===================================================
MAC REMOTE COMMAND CENTER - DESKTOP CLIENT
===================================================

Aplikasi klien mandiri untuk mengendalikan Mac mini tanpa perlu membuka browser.

CARA MENJALANKAN:
1. Di macOS:
   Klik dua kali file 'Mac Remote Client.command'
   (atau jalankan: python3 client_app.py di Terminal)

2. Di Windows:
   Klik dua kali file 'Mac_Remote_Client.bat'
   (atau jalankan: python client_app.py di CMD)

3. Di Linux:
   Jalankan: python3 client_app.py

CARA PAKAI:
1. Masukkan IP server Mac (contoh: 10.66.66.*** atau 192.168.0.***).
2. Port default: 8443.
3. Klik tombol 'Sambungkan'.
4. Nikmati semua fitur: Intercom Pop-Up Chat, Siaran Google Home, Kendali Volume & Layar, File Manager, dan Terminal!
